# My ToDo

My ToDo は、日々のやることを簡単に管理できるシンプルな ToDo アプリです。

ブラウザでそのまま動かせるので、インストール作業がほとんど不要です。予定の追加、完了状態の切り替え、編集、削除、ダークモード切り替えなどを使えます。

## アプリの概要

このアプリは、以下のような場面で使いやすい設計になっています。

- 日々のタスクをメモしたい
- 何を終えたかを視覚的に管理したい
- ブラウザだけで簡単に使いたい
- 完了済みの項目をまとめて消したい

データはブラウザの localStorage に保存されるため、ページを再読み込みしてもタスクが残ります。

## 主な機能

- タスクの追加
  - 入力欄に内容を入れて追加ボタンを押すと、一覧に表示されます。
- タスクの完了切り替え
  - チェックボックスで完了 / 未完了を切り替えられます。
- タスクの編集
  - 既存の項目を編集して、内容を更新できます。
- タスクの削除
  - 1件ずつ削除できます。
- 完了済みタスクの一括削除
  - 完了した項目をまとめて消せます。
- ダークモード切り替え
  - 画面上のボタンでライトモード / ダークモードを切り替えられます。
- 保存機能
  - ブラウザにタスクを保存して、再アクセス時にも状態を維持できます。

## 使用している技術

このアプリは、シンプルな Web アプリとして作られています。

- HTML
  - アプリの構造を作成します。
- CSS
  - 見た目やレイアウト、テーマカラーを整えます。
- JavaScript
  - タスクの追加・編集・削除・保存などの動作を担当します。
- localStorage
  - ブラウザにデータを保存して、再読み込みしても保持できるようにしています。

## 使い方

### 1. アプリを起動する

ブラウザで [index.html](index.html) を開きます。

> そのままローカルファイルとして開いても動作します。

### 2. タスクを追加する

- 入力欄に「買い物」「勉強」などの内容を入力
- 「追加」ボタンを押す
- 一覧に新しいタスクが表示されます

### 3. タスクを完了する

- 項目の左側にあるチェックボックスを押す
- 完了したタスクは打ち消し線付きで表示されます

### 4. タスクを編集する

- 各項目の「編集」ボタンを押す
- 内容を修正して「保存」を押す

### 5. タスクを削除する

- 各項目の「×」ボタンを押すと、そのタスクだけ削除できます
- 「完了済みのタスクを一括削除」ボタンを使うと、完了済みの項目をまとめて削除できます

### 6. ダークモードを切り替える

- 右上のボタンを押すと、ライトモードとダークモードを切り替えられます


## 補足

- このアプリはシンプルな JavaScript で作成されているため、学習用としても理解しやすい構成です。
- 画面の構造とスタイルを分けて書いてあるので、編集しやすくなっています。
- さらに機能を増やしたい場合は、例えば「期限追加」「優先度設定」「並び替え」などを足せます。

## まとめ

My ToDo は、最小限の手間で日々のタスク管理ができる軽い Web アプリです。

シンプルな構成なので、初心者でも読みやすく、JavaScript や HTML の学習にも役立ちます。
